# Buscador de Jugadores - Primera Nacional

Aplicación web desarrollada en Python con Streamlit y Pandas.

Permite filtrar una base de 1.053 jugadores por:
- Equipo
- Posición
- Edad mínima y máxima
- Valor de mercado mínimo y máximo

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

La aplicación se abrirá en `http://localhost:8501`.

## Archivos

- `app.py`: aplicación web.
- `jugadores_primera_nacional_con_posicion.csv`: base de datos.
- `requirements.txt`: dependencias.
